# iad-applied-data-science

В рамках курса Прикладные задачи анализа данных выполнены работы по следующим темам:
- Генеративные и диффузионные модели (файл `gan&diffusion.ipynb`)
  - Подготовка данных
  - Генерация параметров кластеров на изображениях телескопа для заданных типов частиц с помощью GAN'ов
  - Аналогичный эксперимент с диффузионной моделью
- Обработка звука (файл `audio.ipynb`)
    - Обучение рекуррентной сети для классификации аудиозаписей по сырому сигналу
    - Построение мел-cпектрограмм
    - Обучение рекуррентной сети для классификации аудиозаписей по логарифмированным мел-спектрограммам
    - Обучение сверточной сети для классификации аудиозаписей по мел-спектрограммам
    - Применение алгоритма аугментации аудиоданных SpecAugment
- Прогнозирование временных рядов (файл `time-series.ipynb`)
  - Проведение EDA с помощью `ETNA`
  - Построение прогнощов с помощью Prophet
  - Получение иерархического временного ряда
  - Построение признаков и работа с моделями ARIMA и CatBoost
  - Применение разных стратегий прогнозирования
  - Объединение моделей в ансамбль
